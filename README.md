# Evaluación 1 · API de la Copa Libertadores

API REST con Node.js y Express sobre los clubes de la Copa Libertadores.

- 📁 Repositorio: https://github.com/javierfigueroaaaby/evaluacion-1-libertadores
- 🎥 Video: https://www.youtube.com/watch?v=RLo05uv9UfI

## Cómo levantarlo

```bash
yarn
yarn dev
```

El servidor queda en **http://localhost:3000**
